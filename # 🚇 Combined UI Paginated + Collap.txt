## 🏗️ Components Breakdown

| Component | Purpose | Location |
|-----------|---------|----------|
| **Pagination Controls** | Navigate between pages | Top of canvas |
| **Station Card** | Shows station code + name | Per station |
| **Expandable Detail** | Shows full details on click | Below station |
| **Feature Header** | Shows line name + health | Above each line |
| **Progress Bar** | Shows page progress | Bottom of canvas |

---

## 📋 Interaction Flow

```
1. User sees 10 stations per page
         ↓
2. Station cards show: Code + Name
         ↓
3. User clicks a station card
         ↓
4. Card expands below showing:
   - Full file name
   - LOC, Dependencies, References
   - Imports list
   - Referenced By list
         ↓
5. User clicks "Close" to collapse
         ↓
6. User navigates pages with ◀ ▶
```

## 🔧 Implementation Code

```typescript
// ── Pagination State ──
const [currentPage, setCurrentPage] = useState(1);
const [expandedStation, setExpandedStation] = useState<string | null>(null);
const STATIONS_PER_PAGE = 10;

// ── Get paginated stations ──
const getPaginatedStations = (stations, page) => {
  const start = (page - 1) * STATIONS_PER_PAGE;
  const end = start + STATIONS_PER_PAGE;
  return stations.slice(start, end);
};

// ── Render Station Card ──
const StationCard = ({ station, feature, isExpanded, onExpand }) => (
  <div className="flex flex-col items-center min-w-[70px]">
    <div 
      className="cursor-pointer hover:scale-105 transition"
      onClick={() => onExpand(station.id)}
    >
      <div className="w-10 h-10 rounded-full border-2 flex items-center justify-center"
           style={{ borderColor: feature.color }}>
        <div className="w-5 h-5 rounded-full" style={{ backgroundColor: feature.color }} />
      </div>
      <span className="text-[8px] font-bold text-white mt-1">{station.code}</span>
      <span className="text-[7px] text-zinc-400 truncate max-w-[60px]">{station.name}</span>
    </div>
    
    {/* Expanded Details */}
    {isExpanded && (
      <div className="absolute mt-16 z-10 w-64 p-3 bg-zinc-900 border border-border rounded-xl shadow-2xl">
        <div className="flex justify-between">
          <span className="text-xs font-bold text-white">{station.file}</span>
          <button onClick={() => onExpand(null)} className="text-zinc-500">✕</button>
        </div>
        <div className="text-[10px] text-zinc-400 mt-1">
          LOC: {station.loc}  |  Deps: {station.deps}  |  Ref: {station.refs}
        </div>
        <div className="text-[9px] text-zinc-500 mt-1">
          Imports: {station.imports?.join(', ') || 'None'}
        </div>
      </div>
    )}
  </div>
);

// ── Render ──
<div className="space-y-3">
  {/* Pagination */}
  <div className="flex items-center justify-between px-4">
    <button onClick={() => setCurrentPage(p => Math.max(1, p-1))}>◀</button>
    <span className="text-xs text-zinc-400">Page {currentPage} of {totalPages}</span>
    <button onClick={() => setCurrentPage(p => Math.min(totalPages, p+1))}>▶</button>
  </div>
  
  {/* Features */}
  {features.map(feature => {
    const stations = getPaginatedStations(featureLines[feature.id], currentPage);
    return (
      <div key={feature.id} className="border border-border/30 rounded-lg p-3">
        <div className="flex items-center gap-2 mb-2">
          <div className="w-2 h-2 rounded-full" style={{ backgroundColor: feature.color }} />
          <span className="text-xs font-bold text-white">{feature.name}</span>
          <span className="text-[10px] text-zinc-500">({stations.length} stations)</span>
        </div>
        <div className="flex gap-3 overflow-x-auto">
          {stations.map(station => (
            <StationCard
              key={station.id}
              station={station}
              feature={feature}
              isExpanded={expandedStation === station.id}
              onExpand={(id) => setExpandedStation(expandedStation === id ? null : id)}
            />
          ))}
        </div>
      </div>
    );
  })}
  
  {/* Progress */}
  <div className="flex items-center gap-2 px-4">
    <div className="flex-1 h-1 bg-zinc-800 rounded-full">
      <div className="h-full bg-primary" style={{ width: `${(currentPage / totalPages) * 100}%` }} />
    </div>
    <span className="text-[8px] text-zinc-500">{currentPage}/{totalPages}</span>
  </div>
</div>
```

## ✅ Benefits of Combined UI

| Feature | Benefit |
|---------|---------|
| **Pagination** | Fixed number of stations per page |
| **Station Cards** | Codes + names visible |
| **Expand on Click** | Full details only when needed |
| **All Lines Visible** | See all features at once |
| **No Endless Scroll** | Predictable navigation |
| **Click to Inspect** | Focus on what matters |

## 🎯 Summary

| Problem | Solved By |
|---------|-----------|
| Station names too small | Cards with full names |
| Never-ending scroll | Pagination (10/page) |
| Can't see all lines | All features visible |
| Too much info at once | Expand on click |
| Slow navigation | Page controls |
